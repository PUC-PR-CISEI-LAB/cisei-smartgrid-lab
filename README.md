# CISEI Smart Grid Lab — Solicitação de Acesso

Laboratório de pesquisa da PUC-PR (CISEI) dedicado ao estudo de infraestruturas de comunicação para redes elétricas inteligentes: *backhaul wireless* industrial, observabilidade, simulação de redes e inteligência artificial aplicada à operação.

Os repositórios de pesquisa do laboratório são **privados**. O acesso é concedido mediante solicitação e triagem pelo coordenador do laboratório.

## Como solicitar acesso

1. Abra uma [**issue de solicitação de acesso**](../../issues/new?template=access-request.yml) neste repositório.
2. Preencha todos os campos do formulário (vínculo institucional, orientador(a) e linha de pesquisa são obrigatórios para estudantes).
3. A solicitação será triada pelo coordenador. Aprovações resultam em convite do GitHub para o repositório correspondente; a issue é fechada com a decisão registrada.

## Elegibilidade

- Estudantes de pós-graduação e iniciação científica da PUC-PR com orientador(a) vinculado(a) ao laboratório;
- Docentes e pesquisadores da PUC-PR;
- Parceiros externos, mediante acordo institucional prévio.
